[![PowerShell](https://img.shields.io/badge/PowerShell-5.1%2B-blue.svg)]()

**TimeLock** is a powerful Windows productivity tool that helps you stay focused by temporarily blocking distracting applications and hiding folders for a set duration. Perfect for Pomodoro sessions, studying, or deep work blocks.

## ✨ Features

- 🚫 **Block Applications** - Select any running app to block during your session
- 📁 **Hide Folders** - Lock away distracting folders (games, social media, etc.)
- 📝 **Profile System** - Save and load different blocking configurations
- 🎯 **Custom Duration** - Set any time limit from 1 to 1440 minutes
- 🔔 **System Tray Integration** - Runs silently in background
- ⏰ **Real-time Countdown** - Visual timer shows remaining time
- 💾 **Persistent Storage** - Profiles saved as JSON for easy backup

## 📋 Requirements

- Windows 7/8/10/11
- PowerShell 5.1 or higher
- Administrator privileges (for process termination)
